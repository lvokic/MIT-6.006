# Problem Session 6：6-2 至 6-4 复习

## 6-2 Never Return

### 我的思路

根据地标到峡谷的欧几里得距离确定能走的方向，把合法路线看成 DAG。用 DFS 求拓扑顺序，从峡谷做 DAG relaxation，选择距离最小的可达外部地标，再通过 parent 恢复路径。

这个思路正确，和官方答案一致。沿每一条合法边，到峡谷的距离严格增大，所以不可能形成有向环。比较平方距离即可，路线权重仍是小路的长度。

### 实现时需要修正的地方

- 建图时只加入距离严格增大的方向；如果先保留双向边，DFS 和 relaxation 都必须使用同一条件过滤。距离相等时两个方向都不允许。
- `n` 只统计内部地标。只需考虑所有内部地标及其直接相邻的外部地标；每个内部地标最多连接 5 条小路，相关输入规模为 O(n)。这依赖能按内部地标访问其相邻小路。
- 跳过距离为无穷大的节点，选择外部目标时先用 `-1` 表示尚未找到目标。没有可达外部节点时返回无解。
- 平方距离使用整数类型，并遵守坐标差及平方和可表示的假设。返回值应同时包含路线长度和路径。

时间 O(n)，空间 O(n)。实现见 `never_return.hpp`。

## 6-3 DigBuild

### 我的思路

从空图逐条添加转换规则。加入 `b → a` 之前，检查已有图中从 `a` 到 `b` 的路径；用最大转换比例乘以新规则的转换比例，判断是否形成增长环。如果 `a` 无法到达 `b`，新边不形成环。

这个判断方法正确，前提是已加入的规则没有增长环。从空图开始，遇到增长环就返回“禁止”，可以保持这一前提。必须检查最大比例：任意一条路径即使不增长，也不能排除另一条路径形成增长环。

### 需要修正的地方

- 比例比较曾经写反。若 `a → b` 的最大比例是 2 个 b / a，新规则比例为 Q 个 a / b，只有 `2 × Q ≤ 1` 才不会形成增长环。
- 题目给出的是一整组规则。逐条添加是可行的解法，但若每次都运行一次 O(n³) 的 Bellman-Ford，O(n²) 条规则合计可能达到 O(n⁵)，不满足 O(n³)。

### 满足复杂度的整体方法

每种方块作为一个节点，每条规则 `d1 个 b1 → d2 个 b2` 作为一条有向边，权重为 `log₂(d1) - log₂(d2)`。环的总权重为负，当且仅当转换一圈的比例大于 1。添加零权超级起点连接全部类型，运行一次 Bellman-Ford 检测负权环。

节点 O(n)，边 O(n²)，时间 O(n³)。初始 D 的条件保证存在增长环时有足够的方块开始转换。脚手架见 `digbuild.hpp`。

## 6-4 Tipsy Tannister

### 我的思路

从起点 DFS，按每三步喝酒的规则修改或增加节点和边，再用 Bellman-Ford 求最大净收益；如果存在无限增长的获利环，需要考虑无穷大的结果。

### 需要补充和修正的地方

- 相同城镇在不同步数余数下是不同状态。仅按城镇做 `visited` 会合并不等价的情况，应使用 `(town, 步数 % 3)`。
- Bellman-Ford 求最小权重，应把净收益取反，边权为酒费减去道路收税。
- 抵达终点即停止：保留指向终点的边，但终点三个状态都不添加出边。按官方解答，不计到达终点后才发生的酒费；起点出发前的酒费也不能重复计算。
- 对一般有向图，起点可达的负权环还需能到达终点，才能使最终收益无穷大。本题道路双向，因此若起点能到终点，且终点状态已设为终止节点，从起点可达的获利环可走到终点，检测到后即可返回无穷大。终点不可达应先报告无解。

### 正确方法

每个城镇建立三个余数状态；每经过一条道路，余数前进一位，并根据是否需要喝酒设置边权。先检查终点可达性，再从起点状态运行 Bellman-Ford。若有相关负权环，收益无穷大；否则取三个终点状态的最小距离并取反。图有 O(n) 个状态与 O(n) 条边，时间 O(n²)。

更详细的例子和计费方式见 `6-4-tipsy-tannister-notes.md`。

## 这次需要复习的重点

1. **约束必须贯穿所有阶段**：6-2 中拓扑排序和松弛必须使用同一批合法边。
2. **先检查方向与单位**：6-3 中转换比例的分子、分母及乘积判断容易颠倒。
3. **把影响未来决策的信息放进状态**：6-4 中，同一个城镇在不同步数余数下不能合并。
4. **区分方法正确与复杂度满足要求**：6-3 的逐条检查正确，但重复 Bellman-Ford 可能过慢。
